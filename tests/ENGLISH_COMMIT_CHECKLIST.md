# 英文提交手工验证

目标环境：Ubuntu 24.04 + Fcitx5 5.1.7 + fcitx5-rime 5.1.4 + 雾凇拼音。
安装新插件并重启 Fcitx5 后，在普通文本编辑器中验证：

- 输入 `nihao`，看到 `Hello` 提示后按 `Ctrl+Alt+Enter`：只上屏 `Hello`，拼音与候选栏清空；继续打字没有残留中文。
- 用方向键高亮另一条已显示英文的候选，再按快捷键：上屏对应英文。
- 翻页后按快捷键：只使用新页已显示的英文，不提交旧页翻译。
- 快速输入一条未缓存且不在本地词典的短语，在英文出现前按快捷键：插件不拦截、不等待、不替用户提交中文；按键由原输入法/应用处理。
- 空格、数字键和鼠标选词：仍上屏中文。
- 清空输入、切换输入法、禁用 English Hint、进入密码/敏感输入框：快捷键不触发英文提交。
- 在配置工具中修改快捷键后重载配置：新快捷键有效；将快捷键留空并重载：英文提示仍显示，英文提交禁用。
- 多段拼音中已有部分中文选定时使用快捷键：只上屏当前候选的英文，整个组合清空，不追加已选中文或剩余拼音。
- 翻译请求未返回时取消输入，稍后结果返回：不重新弹出候选，不自动提交英文。
