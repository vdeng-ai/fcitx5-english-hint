# 英文提交手工验证

目标环境：Ubuntu 24.04 + Fcitx5 5.1.7 + fcitx5-rime 5.1.4 + 雾凇拼音。
安装新插件并重启 Fcitx5 后，在普通文本编辑器中验证：

以下项目分别在 `VerticalBilingual=False` 和 `True` 两种模式下执行。竖排模式应显示“中文  English”同行，默认模式应保留原中文候选和英文辅助行。

- 输入 `nihao`，看到第 1 项 `Hello` 提示后按 `Alt+1`：只上屏 `Hello`，拼音与候选栏清空；继续打字没有残留中文。
- 当前高亮第 1 项时按 `Alt+2`：上屏第 2 项已显示的英文。高亮第 2 项时按 `Alt+1`：上屏第 1 项英文。
- 部分翻译只显示第 1、3 项时：`Alt+3` 输入第 3 项英文，`Alt+2` 不误选第 3 项。
- 使用数字小键盘 `Alt+2`：同样输入第 2 项英文。
- 翻页后按 `Alt+数字`：只使用新页对应序号已显示的英文，不提交旧页翻译。
- 快速输入一条未缓存且不在本地词典的短语，在英文出现前按 `Alt+数字`：插件不拦截、不等待；按键由原输入法/应用处理。
- `Alt+0`、超出候选/翻译范围的数字、`Ctrl+Alt+2`、`Alt+Shift+2` 和旧的 `Ctrl+Alt+Enter`：插件不触发英文提交。
- 空格、数字键和鼠标选词：仍上屏中文。
- 清空输入、切换输入法、禁用 English Hint、进入密码/敏感输入框：快捷键不触发英文提交。
- 在配置工具中关闭“Alt+数字输入对应候选的英文”并重载：英文提示仍显示，英文提交禁用；重新启用后 `Alt+数字` 恢复有效。
- 多段拼音中已有部分中文选定时使用快捷键：只上屏当前候选的英文，整个组合清空，不追加已选中文或剩余拼音。
- 翻译请求未返回时取消输入，稍后结果返回：不重新弹出候选，不自动提交英文。
- 用键盘和候选窗翻页按钮分别前后翻页，确认英文和新页中文逐项对应；翻回第一页后再次选词。
- 候选未消失时切换“竖排中英同行”：立即切换显示，不叠加两份英文；关闭插件后英文和竖排提示均移除。
- 在多个应用中切换焦点后修改显示模式：旧窗口重新获得焦点时不保留旧模式的翻译显示。
- 检查真实使用的 Classic UI / Kimpanel / 主题：候选不截断到无法辨认，鼠标选中区域和显示的行号一致。自动化集成测试覆盖原候选 `select()` 路径，不替代主题和桌面点击检查。
